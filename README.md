# Electrical Progressive: Four Bay Charger

A four-item charging queue that uses one standard EP charger power budget.

Current source version: **1.0.1**. See [README.txt](README.txt) for usage, compatibility, build instructions and validation limits.

## Source repository

[EPMultiCharger](https://github.com/tannerjriddle97/EPMultiCharger) contains the addon source, authoring files and available test sources. No open-source license has been selected for this source. Game/mod dependencies, local profiles, saves, recovery provenance and generated packages are excluded. Historical audit/probe scripts require a separate deliberate runtime-testing decision; publication does not run them. Interactive acceptance limits remain as documented.
